Problem

If you can't validate biomass, you can't rate the project.

Carbon project developers report biomass and carbon stocks. Rating agencies have to either trust those numbers or build an independent view. We chose the second — which means an EO + field-data pipeline that's consistent across biomes, transparent enough to defend, and resilient to the messy realities of plot data.

The hard parts weren't the models. The hard parts were sensor harmonisation, validation against sparse and noisy field plots, drift across regions, and producing outputs an analyst could trace back to their inputs.

Approach

SAR / optical fusion + field plots + boring rigour.

Inputs

  • Sentinel-1 SAR backscatter (VV / VH, multi-temporal)
  • Sentinel-2 optical (cloud-masked, BOA reflectance)
  • Landsat 8/9 for longer time horizons
  • Environmental covariates (climate, topography)
  • Field plot biomass measurements — the ground truth

Models

  • LULC change detection on multi-temporal stacks
  • Degradation-signal classifiers from SAR + optical fusion
  • Biomass regression: RF / XGBoost ensembles
  • Time-series features for biomass dynamics
  • Uncertainty quantification on every prediction

Validation, not just metrics

  • Built a global forest-plots database to independently validate biomass predictions across biomes.
  • Conducted local fieldwork to strengthen ground-truth inputs where the published data was thin.
  • Drift evaluation across regions surfaced where the model was extrapolating beyond its training distribution.
  • Model validation reported per-biome — a global mean hides the failure modes.
Engineering

Production geospatial, not notebook geospatial.

  • AWS / GCP ingestion pipelines on Airflow, improving provenance and reproducibility across S1 / S2 / Landsat sensors.
  • Standardised STAC metadata and quality checks, reducing dataset inconsistencies by ~30% across regions.
  • Reproducible GitHub repository workflows — pipelines were re-runnable, code-reviewed, and tested.
  • Scheduled workflow automation in Prefect; Snowflake / PostGIS as the analyst-facing store.
Outcome

What it meant for the team

  • AUC > 0.90 on the LULC and degradation models across multiple biomes — defensible signal for ratings.
  • Field-plot calibration loop became a standing capability rather than a one-off.
  • Pipeline patterns (STAC, Prefect, reproducible repos) were reused by adjacent teams.
